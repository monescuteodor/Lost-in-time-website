# Lost-in-time-website

**The website is in Romanian**.

I made a project with my team and my job was to do the website!

Repository for the presentation website and visual assets of **Lost in Time**.

Live Demo: [lost-in-time.teodor-monescu.workers.dev](https://lost-in-time.teodor-monescu.workers.dev/)

- **Branding & Visuals:** Designed the official game logo and the presentation poster for the hackathon.
- **Name:** Lost in Time
- **Genre:** 3D First-Person Platformer with Multiplayer support
- **Setting:** Japan → Forest
- **Core Loop:** The player follows a normal route until encountering a temporal loop block. To advance towards home, players must observe the environment and discover a less obvious path.
- **Frontend:** HTML, CSS for styling and js for functions.
- **Deploy:** Cloudflare Workers
